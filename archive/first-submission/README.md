# Первая сдача (SmartWalk)

Материалы первой версии проекта, когда он ещё назывался SmartWalk. Они сохранены для истории и в текущей сдаче не используются.

- `video/` — сборка первого ролика: раскадровка, закадровый текст, субтитры, проверки качества.
- `video/record-clips.md` — задание на запись клипов с живого сайта для финального ролика; клипы записаны 20 октября, задание выполнено.
- `screenshots/` — скриншоты прежнего интерфейса.
- `build-presentation.mjs`, `build-pdfs.py`, `package_submission.py` — сборщики прежней презентации, PDF и архива. Пути в них указаны от прежних мест и с этой папки не запускаются.

Актуальные материалы: [README](../../README.md), [deliverables/](../../deliverables/).
