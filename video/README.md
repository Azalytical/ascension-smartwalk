# Ascension SmartWalk — видеообзор экранов

Ролик собирается из настоящих скриншотов браузера с русской озвучкой Microsoft Irina Desktop через Windows SAPI. Это обзор экранов прототипа, а не непрерывная запись пользовательского сеанса.

Нужные файлы в папке, указанной в `storyboard.json`:

- `hero.png`: верх страницы, название и карта.
- `planner.png`: выбранный старт, запрос на кофе и 45 минут; видны настройки расчёта.
- `coffee-results.png`: три альтернативы с возвращением и резервом 5 минут.
- `child.png`: результат сценария с ребёнком; видны варианты и ограничения.
- `evidence.png`: раскрытый блок источников у настоящего места и ссылка/атрибуция OpenStreetMap.
- `unknown.png`: предупреждения о неизвестных часах работы, доступе или удобствах; видна оговорка об ориентировочном времени в пути.
- `privacy.png`: открытая политика данных: локация не пишется в историю приложения, а координаты остаются в скачанном плане.

Исходные скриншоты копируются без изменения содержимого в `screenshots/`, с хешами в `screenshot-manifest.json` и историей версий в `screenshot-manifest-history.json`. При финальном рендере все файлы перечитываются из исходной папки. Видеокадры добавляют только внешнее оформление и титры.

Команды из корня проекта с Python, в котором установлен Pillow:

```powershell
python video/build_video.py prepare
python video/build_video.py refresh
# Только когда все скриншоты и формулировки проверены:
python video/build_video.py render
```

Подготовка создаёт SAPI WAV-файлы, общий WAV, русские субтитры, таймлайн и заставку в `video/build/`. Итог — `deliverables/ascension-smartwalk-demo.mp4`, H.264/AAC, 1920×1080, 60–90 секунд, до 100 MB. Используется уже установленный FFmpeg; дополнительная загрузка программ не требуется.

`audio-qa.json` проверяет длительность и ненулевой уровень речи. `mp4-stream-inspection.txt` и `video-qa.json` описывают фактические дорожки и длительность готового MP4; `mp4-decode-check.txt` фиксирует полное декодирование видео и звука. Проверка кодеков не подтверждает качество модели, истинность данных или поведение приложения; это проверяется отдельно по приложению и источникам.
