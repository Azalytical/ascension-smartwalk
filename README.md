# SmartWalk · Город в вашем темпе

Команда **Ascension**, Build with AI Hackathon 2026, AI for Smart City.

Помощник для прогулок по Астане: пользователь выбирает старт через GPS, поиск по базе мест или карту, задаёт 10–180 минут, бюджет в тенге и особые пожелания. Сервис предлагает **одно место**, с понятным планом и до двух альтернатив. Время каждого варианта отдельно включает дорогу туда, визит, возвращение и запас 5 минут.

Эти изменения подготовлены в ветке **Alisher**. Публикация ветки не меняет `main` и действующий сайт.

## Что изменено

- Поиск старта по всем пригодным точкам корпуса вместо трёх фиксированных локаций. GPS запрашивается только по нажатию; после отказа остаются поиск и карта.
- Общие быстрые варианты: «Поесть», «Погулять», «Культура», «Необычное». Они сохраняют выбранную геопозицию, время и бюджет.
- Общее время 10 минут — 3 часа. Отдельного обязательного ползунка пути нет; ограничение можно написать в пожеланиях, например «не больше 10 минут пешком».
- Бюджет на человека и средний чек, если он известен из источника. Неизвестный чек явно отмечается и не выдаётся за подтверждённое соответствие бюджету. Для запроса «бесплатно» нужны положительные данные о бесплатном посещении.
- Особые пожелания, режим под крышей и прогулка с ребёнком. Обязательные условия требуют подтверждения; отсутствие данных не означает соответствие.
- Gemini / OpenAI выбирает один `preferredId` среди кандидатов, прошедших проверки географии, времени и условий. Сервер проверяет ID и ссылки. Модель пишет короткий совет своими словами в ограниченном нейтральном словаре; название подставляется сервером через `{{name}}`. Произвольные числа, неизвестные названия, URL, утверждения о событиях и услугах отклоняются. Время, цены и прочие факты отображаются отдельно из проверенной записи.
- На телефонах поля не вызывают автоматическое увеличение, кнопки доступны касанием, карта не перехватывает прокрутку. Полноэкранная карта закрывается кнопкой или Escape и возвращает управление странице.
- Карточка показывает название, категорию, описание, расстояние, разложение времени, часы, известные контакты/Instagram, чек, рейтинг и источники. Для парков контакты заведения не навязываются.
- Скачивание выбранного плана в читаемый HTML: открывается в браузере и печатается в PDF. Точная GPS-точка, исходный запрос и личные пожелания в него не включаются. Сохранение на сервер не выполняется.
- Единые SVG-иконки и новый знак SmartWalk, подготовленные отдельным чатом.

## Как работает RAG

1. Скрипт `scripts/import_osm_pois.py` автоматически собирает POI через Overpass; исходные ответы и происхождение сохранены в `data/`. Импорт Eventura воспроизводим отдельно.
2. Сервер извлекает кандидатов по координатам, категориям и словам запроса, проверяет часы, время, бюджет и подтверждения обязательных условий. Embeddings не используются.
3. Gemini получает только подходящие публичные места, запрос и пожелания без точной координаты старта. Выбирает один ID и генерирует короткий совет с идеей для визита.
4. Сервер проверяет ID, ссылки и текст. Нейтральная формулировка модели сохраняется; конкретные факты не переписываются моделью. Недопустимый ответ заменяется явно обозначенным подбором без генерации.
5. Пользователь видит один план, до двух альтернатив, разделение «Совет ИИ» / «Из данных места», оценку времени и источники. Идеи посещения помечены как идеи.

С ребёнком можно явно выбрать музей или кафе; категория не подтверждает безопасность, возрастные условия и интерактивность. Интерактивность требует отдельного тега. Отрицание вроде «розетка не нужна» не превращается в требование; «обязательно розетка, желательно тихо» разделяет обязательное условие и пожелание. Неизвестные обязательные свойства дают честный пустой ответ. Разбор текста использует ограниченный словарь ru/en/kk и не гарантирует понимание произвольных формулировок.

## Данные Eventura

Папка Eventura читалась без изменений. Импортированы **994** записи публичного справочника из `places-2gis.json` и `places.json`: 973 Астана, 20 Косшы, 1 Караганда; одна пустая строка отброшена. Моки, личные данные, отзывы отдельных авторов, бронирования, фотографии и секреты не переносились.

В исходных выгрузках отсутствуют координаты, часы работы и средний чек. Они остаются `null`. Поэтому записи без координат сохранены в `data/eventura-venues.json`, но не участвуют в подборе маршрута. Нельзя считать все 994 записи дополнительными доступными местами прогулки.

Для **15** существующих OSM-точек подтверждено совпадение названия, улицы и номера дома. Их рейтинг, число отзывов и доступные контактные данные дополняются при загрузке через `src/catalog.mjs`; координаты и происхождение OSM сохраняются. Каждый добавленный факт имеет отдельный источник 2GIS/Google и неизвестную дату исходного снимка. Рейтинг и число отзывов не считаются текущей посещаемостью. Имена разных филиалов сами по себе не основание объединения.

Файлы `data/eventura-enrichment.json` и `data/eventura-import-metadata.json` содержат доказательства сопоставления и SHA256 исходников. Лицензия локальных выгрузок не указана; они не переобозначены как ODbL. Для дальнейшего распространения справочника следует учитывать условия исходных каталогов.

Воспроизводимый импорт (источник только читается):

```sh
python3 scripts/import_eventura_venues.py --help
python3 scripts/import_eventura_venues.py --eventura-dir /path/to/Eventura --osm-file data/pois.json --output-dir data
```

Apify отложен по просьбе пользователя. Внешний скрейпер и его ключи для этой версии не нужны.

## Локальный запуск

Node.js 22+:

```sh
npm install
npm test
npm run dev
```

Откройте `http://localhost:8789`. Доступный API-ключ читается только из окружения процесса: `GEMINI_API_KEY` (опционально `GEMINI_MODEL`) или `OPENAI_API_KEY` (опционально `OPENAI_MODEL`). Секреты в клиент и Git не попадают. `.env.example` автоматически не загружается. Без ключа или при сбое провайдера подбор по данным продолжает работать с явным указанием отсутствия ИИ.

```sh
npm run build
```

Создаётся единый Cloudflare Worker в `dist/server/index.js` со всеми клиентскими ассетами и объединённым корпусом. Доступны `GET /api/status`, `GET /api/locations?q=...&limit=30`, `POST /api/recommend`. Поля запроса: `lat`, `lon`, `minutes`, `query`, `preferences`, `budget` (KZT или `null`), `withChild`, `indoor`, `returnToStart`; прежний `maxWalkMinutes` поддерживается API.

Развёртывание Cloudflare/Cloud Run и Telegram-бот сохранены. Для Cloudflare: `npm run build`, `npx wrangler secret put GEMINI_API_KEY`, `npx wrangler deploy`. Публикацию этой ветки в production не выполняли.

## Ограничения и приватность

- География корпуса — Астана. Оценка времени: расстояние по прямой × 1,35, скорость 4,2 км/ч. Переходы, ограждения и реальные проходы не проверяются. Пунктир на карте не является пешеходной навигацией.
- Посещение — плановая оценка. При коротком окне визит сокращается до допустимого минимума категории и обозначается; посещение выставки или обслуживание за это время не обещается.
- Часы из снимка проверяются на время визита, но открытие сейчас, праздники, очереди и события не подтверждаются. Неизвестные сведения не угадываются.
- История координат и запросов в приложении не ведётся. Сервер получает точку для расчёта, модель — текст и проверенные записи без точных координат старта. Введённый пользователем адрес внутри текста может быть передан провайдеру; не вводите личные данные. Для OpenAI задаётся `store:false`. Действуют условия внешнего провайдера; бесплатный Gemini может использовать запросы для улучшения продуктов.
- Карта, шрифт и библиотека карты загружаются с OpenStreetMap, Google Fonts и unpkg. Они получают обычные сетевые данные, включая IP.
- На размещённом сервисе прежние лимиты генерации сохранены: до 8 запросов в минуту с адреса и 500 в сутки в памяти Worker/одного контейнера, либо настроенный D1/rate limiter.
