# Проверка ветки Alisher — 19 октября 2026

Изменения подготовлены по задаче НИЦ Smart City «ИИ-помощник по прогулкам в городе Астана», присланной пользователем. Требования CampusPulse к MCP и Vertex AI относятся к другому кейсу.

## Проверено

- `npm test`: 57 тестов пройдены; `npm run build` успешно; `git diff --check` без ошибок.
- Серверный поиск по корпусу вместо трёх фиксированных стартов; валидные координаты Астаны и ограничение выдачи.
- Границы 10 и 180 минут; проверка времени туда + посещение + возвращение + 5 минут запаса.
- Бюджет, неизвестный средний чек, подтверждённые обязательные условия, пустой ответ при отсутствии подтверждения.
- API Gemini/OpenAI принимает запрос и пожелания без точных координат старта, выбирает ID только из проверенных кандидатов. Выбор и отклонение неверного ID проверены с имитацией ответа провайдера.
- В браузере: ручной поиск Байтерека, получение рекомендации, смена основного места через альтернативу, открытие/закрытие карты и Escape, скачивание HTML.
- Desktop 1440px и mobile 390px: снимки просмотрены; горизонтального переполнения нет. Прокрутка над встроенной картой сдвинула страницу с 945 до 1185px. Карта возвращается из диалога на страницу.
- Скачанный HTML открываемый, содержит печать и источники, не содержит исходного запроса. Экспорт исключает точную точку старта и персональные предупреждения, сформированные по условиям пользователя.
- Независимый Impeccable finish review: `ship` в пределах проверенной композиции и кода. Маленький дефект сообщения при таймауте поиска исправлен. Документер подтвердил согласованность README, сохранённую палитру/Golos и отсутствие необходимости менять прежний дизайн-контекст.
- Eventura только читалась: импортировано 994 записи, 973 из Астаны. Координат/цен/часов в исходных выгрузках нет. Только 15 совпадений имени и полного адреса обогащают существующие OSM-точки; исходные файлы проверены SHA256. Координатный корпус остаётся 930 POI.

## Границы подтверждения и продолжение

- Реальный локальный вызов провайдера вернул `generation.mode=fallback`, `reason=provider_unavailable`. Это не доказательство успешной генерации Gemini. На production Gemini уже был настроен ранее; его ключи и работающий сайт эта ветка не меняет.
- Видимое краткое резюме строится из выбранной проверенной записи; модель выбирает основной ID. После продолжения отдельно проверить качество объяснения Gemini по требованиям RAG и реальный ответ с рабочим ключом.
- Имитация callback GPS (разрешение с координатой и отказ code=1) пройдена в браузере; после отказа доступен ручной поиск. Проверены также пустой ответ на неподтверждённое обязательное условие, предупреждение об неизвестной цене, скрытие старого результата после изменения бюджета и отсутствие личного запроса/бюджета/GPS в скачанном файле.
- Реальное получение GPS в браузерной среде не подтверждено: системная геолокация вернула ошибку, интерфейс предложил ручной выбор. Сценарий с физическим телефоном остаётся для продолжения.
- Наличие поля среднего чека не создаёт цены: в имеющихся источниках они отсутствуют. Для полного покрытия Eventura нужны проверенные координаты/геокодирование и сведения о ценах.
- Слайды, видео и прежние протоколы относятся к старой версии. Полное прохождение T01–T12 и новая презентация этой проверкой не заявляются.
- Apify отложен пользователем.
- По поручению пользователя работа останавливается после короткой сессии и возобновляется только по его сообщению. Ветка Alisher; main и production не менялись.
