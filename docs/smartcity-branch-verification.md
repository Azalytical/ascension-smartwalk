## Проверенные сценарии

**Автотесты.** Границы 10/180, арифметика возврата, закрытие к концу визита, дубли, запретные точки, категории ru/en/kk, бюджет и бесплатный вход, неоднозначные/обязательные предпочтения, отрицания и область действия «обязательно / желательно», ребёнок + музей, подтверждение интерактивности, источник добавленного рейтинга, лимиты API, ошибки провайдера и приватность модельного контекста.

**Генерация с контролируемыми ответами провайдера.** Валидный ID, сохранение собственной нейтральной формулировки ru/en/kk, отклонение неизвестного места, выдуманных чисел/цен/событий, URL и инструкций. Название подставляет сервер; ограниченный словарь не позволяет перенести неподтверждённые факты в сгенерированный текст. Это ограничивает свободу формулировок; при нарушении контракта показан запасной вариант, а не непроверенный ответ.

**Браузер.** Выбор Байтерека клавиатурой; быстрый вариант «Поесть» с сохранением старта и времени; запрос с ребёнком; «розетка не нужна»; бюджет с неизвестными ценами; переключение альтернативы; очистка устаревшей выдачи при смене бюджета; сохранение HTML. В файле сохранены печать, источники и нейтральное предупреждение о цене, но отсутствуют контрольный личный текст и точная стартовая GPS-точка.

**Мобильный браузер.** Geolocation API с выданным браузерным разрешением и координатой эмулятора успешно установил старт. Это не подмена callback приложения. Настоящий touch-свайп над встроенной картой прокрутил страницу с 963 до 1162,5 px. Полноэкранная карта открылась и закрылась касанием, после чего вернулась в страницу. Физический GPS на личном телефоне не проверялся.

**Маркировка ИИ.** Показ «Совет ИИ» проверен в интерфейсе с явно имитированным ответом API. Итоговые снимки `resume-desktop.png` и `resume-mobile.png` показывают обычный честный режим «По данным мест» без ключа; имитация не выдана за живой вызов модели.

## Что не добавлено и не подтверждено

- Новый ключ Gemini не вводился и не копировался: пользователь не является владельцем настроенного ключа. Подключение API было в исходном проекте, его код расширен, конфигурация production не изменена. Реальный вызов новой ветки с ключом владельца не подтверждён.
- Apify не подключался по просьбе пользователя; нового запуска внешнего скрейпера не было.
- Реальные цены/средний чек, часы и координаты отсутствующих записей Eventura не добавлялись. Неизвестные поля остаются неизвестными. Варианты без координат не выдаются как доступные точки маршрута.
- Не подключались данные о текущих выставках, очередях, свободных столиках и доступности в реальном времени. Такие сведения не выдумываются.
- Отдельная модель не обучалась; используется предусмотренный API Gemini/OpenAI. Embeddings не нужны для реализованного поиска по словарю и географии.
- Физический телефон, спутниковый GPS и реальный пеший маршрут на местности не проверялись. Подтверждена браузерная мобильная эмуляция, стандартный Geolocation API и touch-жесты.
- Новая презентация, видео и выкладка сайта в production не выполнялись. Изменения находятся только в ветке Alisher; локальный просмотр работает отдельно.

## Данные Eventura

994 записи сохранены отдельным справочником: 973 Астана, 20 Косшы, 1 Караганда; одна пустая строка отброшена. В выгрузках нет координат, часов и среднего чека. Поэтому все 994 записи не считаются дополнительными доступными точками маршрута. Только 15 совпадений названия и полного адреса дополняют существующие OSM-точки. Исходные файлы Eventura не изменялись; SHA256 сохранены в `data/eventura-import-metadata.json`. Происхождение и неизвестная лицензия каталогов не заменены ODbL.

## Границы проверки

- У действующего демо `GET /api/status` подтвердил `generationProvider=gemini`; код/настройки сайта не менялись. Ключ владельца недоступен локально, Cloudflare CLI не авторизован. Пользователь сообщил, что ключ не его. **Живой вызов Gemini для новой ветки не подтверждён**; использованы контролируемые ответы провайдера.
- Среднего чека и координат для всех записей Eventura нет. Для расширения покрытия нужны реальные данные/проверенное геокодирование. Цены не придуманы. Apify отложен пользователем.
- Разбор свободного текста ограничен словарём и поддерживаемыми условиями. Это не обещание понимания любых требований и не гарантия безопасности/доступности места.
- Старые слайды, видео и протоколы в `deliverables/` относятся к прежней версии. Полное повторное прохождение T01–T12 и новая презентация не заявляются.
