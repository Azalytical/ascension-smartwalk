# Презентация Aidem для защиты (6:00, трое)

`index.html` открывается двойным щелчком в Chrome или Edge и работает без интернета: шрифты, анимации (GSAP), кадры у AITU, экраны телефона и QR-код лежат в `assets/`. Интернет нужен только для живого демо. Копируйте папку `deck` целиком, а не один `index.html`.

Нажмите **F** для полного экрана. Если клавиши не реагируют, один раз щёлкните по слайду.

| Клавиша | Что делает |
|---|---|
| → , пробел, Enter, PageDown, кликер | следующий слайд (первое нажатие запускает таймер 6:00) |
| ← , Backspace, PageUp | назад |
| Home / End | первый / последний слайд (Home заново проигрывает титул и сбрасывает таймер) |
| F | полный экран |
| S | окно докладчика: кто говорит, заметки, следующий слайд, таймер и отставание от плана |
| D | открыть живое демо в новой вкладке (на слайде «Кофе за 45 минут» есть такая же кнопка) |
| B | чёрный экран |
| M | анимации вкл/выкл |
| H | подсказка по клавишам |

Кто говорит (номера как на слайдах, титул 00): Азамат 00–03, на 03 «Кофе за 45 минут» живое демо, он остаётся за ноутбуком; Данияр 04–08; Алишер 09–13. Окна по времени стоят в `data-time` у каждого слайда и в начале заметок `<aside class="notes">`; по ним же строится полоса внизу слайдов.

`index.html?slide=7` открывает сразу седьмой слайд, `?motion=0` показывает всё без анимаций.

## PDF

`ascension-smartwalk-presentation.pdf` уровнем выше собирается из этих же слайдов с текстовым слоем:

```sh
npm i --no-save playwright && node deliverables/deck/build-pdf.mjs
```

Нужен `pdfunite` (poppler-utils). Скрипт открывает `index.html?pdf=1` (без анимаций, вместо видео стоит кадр), печатает каждый слайд отдельно и склеивает страницы.

## Ресурсы

- `assets/video/aitu.mp4` — вход в AITU, снято командой 20 октября (IMG_8725, замедлено, туда и обратно 12 с); `assets/img/aitu-poster.jpg` — кадр из него для PDF.
- `assets/img/door-phone.jpg` — кадр из той же съёмки для слайда «Проблема».
- `assets/img/*-N.jpg` — экраны сайта 390×844 из прежних скриншотов колоды и `screens-v5` строгого жюри.
- `assets/js/places.js` — координаты 2255 мест для фона из точек.
- QR-код на финальном слайде ведёт на https://ascension-smartwalk.azamatbreach.workers.dev (проверен декодером jsQR).
